# Рекрут GOVFOR

`RuCMJobGOVFORRecruit` — отдельная профессия обучения, не новый qualification ID.
Аккаунт без действующего военного уровня показывает статус «Рекрут», но выбор этой
должности сам по себе не сбрасывает уже имеющиеся квалификации.

## Выбор и прибытие

В настройках персонажа: Восстание → Правительственные силы → линейный состав →
«Рекрут GOVFOR». При позднем входе роль появляется в группе GOVFOR на действующей
базе/корабле. Без требований по времени, военному уровню и профессии. Баны и
обычные проверки выбора роли остаются у штатного GameTicker.

`rucm.qualifications.recruit_slots` — количество мест, по умолчанию 64, максимум
1024; 0 отключает роль. Система добавляет места перед назначением профессий через
публичный RulePlayerSpawningEvent и поддерживает новые станции через Update.
Обновление количества мест учитывает уже занятые места. Вне Восстания места закрыты,
а кандидаты, прямой выбор и запрос позднего входа ограничены публичными событиями.

Приоритет прибытия: собственный маркер `RuCMSpawnPointGOVFORRecruit`, существующий
маркер инструктора, стрелка, GOVFOR latejoin, обычный latejoin на корабле GOVFOR.
Последний вариант поддерживает USS Bush и USS Bush Redux без изменения карт.
Для выбранного ship-side используются
только GOVFOR корабли; для planet-side только основная планетная станция без
кораблей обеих сторон. Без подходящей точки места не добавляются. Новая карта или
отдельная учебная комната не создаются; сервер может разместить собственный маркер.

## Снаряжение и обучение

Форма, пустые ботинки, сумка, гарнитура, собственное удостоверение и физическое
учебное пособие, открывающее GOVFOR Guidebook. В комплекте нет оружия, боеприпасов
или боевой брони. Удостоверение имеет только AU14AccessGovfor, без Squad, командных,
оружейных и профессиональных доступов; extended access также пустой. Loadout пустой,
поэтому боевая экипировка стрелка не наследуется. Начальные навыки не наследуются
из пресета стрелка; используются нулевые firearms/construction/medical.

Для любого выбранного взвода используется штатное звание `RMCRankRecruit`, E0,
и универсальный знак различия `CMUChevronRecruit`. Звание установлено уже при
создании персонажа, до загрузки таймеров аккаунта. Форма и пустые ботинки рекрута
и инструктора задаются полями `recruitGear`/`instructorGear` прототипа взвода:
USCM, LACN, UPP, WEYU, CMBCIU, HAZOPS, ProdigySF, VAIPO и RMC.
Инструктор сохраняет штатные навыки, доступы, loadout и знаки различия CMU,
получает префикс «ИНСТР»; выбранный в loadout головной убор сохраняется.
Эти изменения формы и префикса применяются только в Восстании.
Штатная система знаков различия применяет звание при вставке знака в надетую форму
и при повторном надевании формы; снятие знака или формы возвращает звание профессии.
Базовое звание назначается до выдачи знака выбранного взвода.

Штатный spawn helper не назначает рекрута в боевой отряд. Дополнительное удаление
из отряда после появления остаётся защитой для альтернативных путей спавна.
Наставник автоматически не назначается. Надзор и выдача учебного оружия остаются
у инструктора/командования. Получение Enlisted открывает соответствующие профессии
при следующем выборе роли; не переэкипирует и не переводит текущего персонажа.
Начальное обучение доступно даже при временно недоступном хранилище квалификаций;
остальные боевые gates продолжают использовать существующую failure policy.

## Настройки персонажа

Поле профессии `characterSetupPresets` ограничивает вкладки штатного редактора.
У рекрута задано `[Insurgency]`, поэтому роль не показывается в FoF и Distress.
Пустое поле сохраняет прежнее отображение остальных профессий. Сервер дополнительно
исключает рекрута из кандидатов и запрещает прямые запросы вне Восстания.

## Scope and validation

Нет автоматического изъятия чужого оружия, назначения E4+ наставника, CO bypass,
экзамена, смены профессии в текущем раунде или выдачи квалификации за время службы.
Базовый доступ не запрещает взять оставленный предмет; существующие общедоступные
автоматы и карты не переписаны. Уставной контроль учебного оружия остаётся RP.
Регрессионные проверки находятся в `CMURecruitCmuParityTest`: загрузка обеих
реальных карт USS Bush, доступность и создание рекрута, сохранение занятых мест,
отделение кораблей двух сторон и гражданских точек, форма девяти взводов,
звание E0, снятие/крепление знака и повторное надевание формы,
сохранение обычного советника вне Восстания.
